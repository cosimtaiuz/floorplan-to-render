# Code of Conduct

## Our standard

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. The canonical text is maintained at that link and applies in
full to every space this project uses: issues, pull requests, discussions and
commit history.

In short: everyone is welcome here regardless of background or experience, and
participation is expected to be respectful. Harassment, personal attacks,
demeaning or discriminatory comments, and publishing others' private information
are not acceptable.

Technical disagreement is not a conduct problem — arguing that an approach is
wrong is fine, and welcome. Making it about the person is not.

## Scope

This applies to anyone participating in the project's spaces, and to anyone
representing the project in public.

## Reporting

Report conduct issues privately to the maintainers rather than in a public
thread. If a maintainer is the problem, say so in the report; it will be handled
by someone else where that is possible.

Reports are kept confidential. Maintainers will respond as promptly as they can
and may remove comments, close issues, or block accounts as needed.
